# Capsule Lite — v1.3.3 (versionCode 41)

Capsule Lite is an Android Dynamic Island-style overlay for charging, calls, media, notifications, and supported live activities.

## Current build

- **App version:** 1.3.3
- **Android version range:** Android 7.0+ (minSdk 24; behavior and permissions vary by Android version and device vendor)
- **Build:** Debug APK generated by GitHub Actions
- **Artifact:** `capsule-lite-v41-debug-apk`

## v1.3.3 settings UI redesign

- Settings cards now use a clearer title hierarchy and section-specific descriptions.
- Dividers and adjusted spacing make each group of controls easier to scan.
- Card surfaces, borders, and elevation adapt to Light, Dark, and AMOLED themes.
- Existing settings controls and preference keys are preserved; this build focuses on presentation.

See [BUILD_TIMELINE.md](BUILD_TIMELINE.md) for version-by-version build outputs and CI links.

## Features in the consolidated source

- **Live-activity priority and handoff:** recognizes supported timer/progress notifications, gives timers priority over progress updates, briefly shows completion, then hands off to another eligible activity or a queued ordinary notification.
- **Per-app live-activity allow-list:** optional comma-separated package names; blank means all eligible apps, subject to the Privacy hidden-app list.
- **Reduced motion:** provides a dedicated option to reduce entrance/morph motion while respecting the global animation setting and Android animator scale.
- **App appearance:** System, Light, Dark, and AMOLED app themes; charging-pill appearance settings remain separate.
- **Separate charging pill:** configurable size and vertical offset, selectable icon styles/shapes, independent gestures, expand/collapse, and charging details.
- **Accessibility and usability:** home tile descriptions, slider value announcements, theme-aware text/editable fields, package-name fields without autocorrect, and save/reset confirmations.
- **Settings backup and restore:** versioned JSON backups, older-backup compatibility, 1 MB import limit, numeric range checks, explicit restore confirmation, merge behavior for settings present in the file, and success/failure feedback.

## Download the APK

1. Open the [latest successful v40 GitHub Actions run](https://github.com/alimuhammed8287/capsule-lite-android/actions/runs/40326572203).
2. Scroll to **Artifacts** and download `capsule-lite-v42-debug-apk`.
3. Extract the ZIP and install `app-debug.apk`. Android may ask you to allow installation from the app used to open the file.

The artifact expires on **November 9, 2026**. This is a debug APK, not a Play Store release.

## Build from source

1. Open the project root (the directory containing `settings.gradle.kts`) in Android Studio.
2. Use JDK 17 and allow Gradle to resolve the Android Gradle Plugin and dependencies.
3. Run **Build → Make Project**, or run `gradle --no-daemon --stacktrace assembleDebug` from the project root.
4. The APK should be at `app/build/outputs/apk/debug/app-debug.apk`.

GitHub Actions runs `scripts/validate_source.py`, checks Android XML, compiles `assembleDebug`, and uploads the debug APK. See [workflow runs](https://github.com/alimuhammed8287/capsule-lite-android/actions).

## Test plan and limitations

Use the checklist below to test the installed app. CI validation and compilation do not replace testing on a physical phone.

## Manual device test checklist

### Permissions and first launch
- [ ] Confirm the app opens. Review overlay, notification access, and Android 13+ notification permission behavior.
- [ ] Check diagnostics for clear missing-permission status.

### Themes and accessibility
- [ ] Switch System, Light, Dark, and AMOLED themes; inspect headings, buttons, switches, hints, text fields, status messages, and tile arrows.
- [ ] Verify pill appearance is independent from the app theme.
- [ ] If using TalkBack, test home tile descriptions and slider value announcements.
- [ ] Test global animation and reduced-motion settings.

### Charging pill and gestures
- [ ] Test charging visibility, width, height, vertical offset, icon styles, and icon shapes.
- [ ] Test tap, double-tap, and long-press independently.
- [ ] Expand/collapse the pill and check percentage, ETA, temperature, and watts when available.
- [ ] Unplug the charger; confirm the secondary pill disappears.
- [ ] Test charging while notifications, media, calls, and Maps are active.

### Notifications and live activities
- [ ] Test ordinary notifications, supported action buttons, and quick replies.
- [ ] Test calls and media controls.
- [ ] Try timer/stopwatch and progress notifications from apps that publish supported ongoing notifications.
- [ ] Verify timer priority, completion display, and handoff to the next eligible activity.
- [ ] Test live-activity allow-list, hidden-app list, and driving mode.

### Settings and backup
- [ ] Save custom lists and confirm success feedback.
- [ ] Export settings; cancel a restore and verify nothing changes.
- [ ] Restore a backup and confirm matching settings are applied while absent keys remain unchanged.
- [ ] If available, test an older backup without version metadata.
- [ ] Test reset cancellation; only confirm reset when intentionally clearing preferences.
- [ ] Keep a backup before testing malformed or oversized JSON files.

### Background behavior and bug reports
- [ ] Switch apps, lock/unlock, and test background behavior.
- [ ] Check that hiding the secondary pill does not leave an invisible touch overlay.
- [ ] For a bug, record exact steps, expected versus actual behavior, phone model, Android version, and whether it reproduces consistently.

**Reminder:** CI success confirms static checks and APK compilation; it does not confirm all behavior on a physical device.
