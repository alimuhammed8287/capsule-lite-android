# Capsule Lite — v1.3.2 (versionCode 40)

Capsule Lite is an Android Dynamic Island-style overlay for charging, calls, media, notifications, and supported live activities.

## Current build

- **App version:** 1.3.2
- **Android version range:** Android 7.0+ (minSdk 24; behavior and permissions vary by Android version and device vendor)
- **Build:** Debug APK generated by GitHub Actions
- **Artifact:** `capsule-lite-v40-debug-apk`

## Features in the consolidated source

- **Live-activity priority and handoff:** recognizes supported timer/progress notifications, gives timers priority over progress updates, briefly shows completion, then hands off to another eligible activity or a queued ordinary notification.
- **Per-app live-activity allow-list:** optional comma-separated package names; blank means all eligible apps, subject to the Privacy hidden-app list.
- **Reduced motion:** provides a dedicated option to reduce entrance/morph motion while respecting the global animation setting and Android animator scale.
- **App appearance:** System, Light, Dark, and AMOLED app themes; charging-pill appearance settings remain separate.
- **Separate charging pill:** configurable size and vertical offset, selectable icon styles/shapes, independent gestures, expand/collapse, and charging details.
- **Accessibility and usability:** home tile descriptions, slider value announcements, theme-aware text/editable fields, package-name fields without autocorrect, and save/reset confirmations.
- **Settings backup and restore:** versioned JSON backups, older-backup compatibility, 1 MB import limit, numeric range checks, explicit restore confirmation, merge behavior for settings present in the file, and success/failure feedback.

## Download the APK

1. Open the [latest successful v40 GitHub Actions run](https://github.com/alimuhammed8287/capsule-lite-android/actions/runs/40319436164).
2. Scroll to **Artifacts** and download `capsule-lite-v40-debug-apk`.
3. Extract the ZIP and install `app-debug.apk`. Android may ask you to allow installation from the app used to open the file.

The artifact expires on **November 9, 2026**. This is a debug APK, not a Play Store release.

## Build from source

1. Open the project root (the directory containing `settings.gradle.kts`) in Android Studio.
2. Use JDK 17 and allow Gradle to resolve the Android Gradle Plugin and dependencies.
3. Run **Build → Make Project**, or run `gradle --no-daemon --stacktrace assembleDebug` from the project root.
4. The APK should be at `app/build/outputs/apk/debug/app-debug.apk`.

GitHub Actions runs `scripts/validate_source.py`, checks Android XML, compiles `assembleDebug`, and uploads the debug APK. See [workflow runs](https://github.com/alimuhammed8287/capsule-lite-android/actions).
